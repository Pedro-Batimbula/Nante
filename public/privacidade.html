Política de Privacidade do Nante

Última atualização: 19 de novembro de 2026

O Nante (“Não te errites!”) é um jogo de tabuleiro online para 2 a 4 jogadores, disponível em nante.onrender.com e na aplicação Android com o mesmo nome. Esta página explica que dados pessoais recolhemos, para que os usamos e que direitos tens sobre eles.

1. Quem é o responsável

O responsável pelo tratamento dos dados é Rasso Nexus. Para qualquer questão sobre privacidade, escreve para dradas182005@gmail.com.

2. Que dados recolhemos

  • Dados da conta: o nome de utilizador (e o email, se o indicares) e a palavra-passe. A palavra-passe é guardada de forma protegida e não é visível para nós.
  • Dados de jogo: as partidas em que participas, resultados, pontuações e as jogadas feitas durante o jogo.
  • Dados técnicos: o endereço IP e registos básicos do servidor (data e hora do acesso, tipo de dispositivo e de navegador), usados para o jogo funcionar e para proteger o serviço contra abusos.
  • Armazenamento no dispositivo: guardamos no teu dispositivo a informação necessária para manter a sessão iniciada e as tuas preferências.

Não recolhemos a tua localização, contactos, fotografias, microfone nem câmara.

3. Para que usamos os dados

  • Criar e gerir a tua conta e permitir que inicies sessão.
  • Ligar-te a outros jogadores e mostrar o estado das partidas em tempo real.
  • Manter o serviço seguro e resolver problemas técnicos.

Não vendemos os teus dados e não os usamos para publicidade.

4. Com quem partilhamos

Os dados são tratados pelos serviços de alojamento que fazem o jogo funcionar (servidor e base de dados). Estes prestadores só tratam os dados por nossa conta e para esse fim. Os teus dados também podem ser vistos por outros jogadores na medida em que isso faz parte do jogo, por exemplo o teu nome de utilizador durante uma partida. Fora isso, só os partilhamos se a lei o exigir.

5. Quanto tempo guardamos

Guardamos os dados da conta enquanto a conta existir. Se a eliminares, apagamos os dados associados, exceto o que formos obrigados a conservar por lei.

6. Os teus direitos

Podes pedir acesso aos teus dados, a correção deles, a eliminação da tua conta e dos dados associados, ou opor-te a certos tratamentos. Para exercer qualquer destes direitos, escreve para [EMAIL DE CONTACTO] e respondemos o mais depressa possível.

7. Eliminar a conta e os dados

Para eliminar a tua conta e os dados associados, envia um pedido para dradas182005@gmail.com a partir do email da conta, indicando o teu nome de utilizador.

8. Crianças

O Nante não se destina a crianças com menos de 13 anos e não recolhemos intencionalmente dados dessa faixa etária. Se achas que uma criança nos forneceu dados, contacta-nos para os apagarmos.

9. Alterações a esta política

Podemos atualizar esta política. Quando o fizermos, mudamos a data no topo da página.
